# 실시간 강의실 — QR로 참여하는 강의 요약 & 퀴즈

강의 시간에 QR 하나를 띄우면, 학생들이 각자의 폰으로 들어와
**강의 요약을 보고 → 퀴즈를 풀고 → 명예의 전당에서 겨루는** 웹앱입니다.

빌드 도구도, npm 패키지도 없습니다. 정적 파일 6개가 전부입니다.

```
class/
├─ index.html    화면 껍데기
├─ style.css     모바일 우선 스타일
├─ app.js        라우터와 모든 화면
├─ store.js      저장소 (Firebase RTDB | localStorage)
├─ payload.js    강의를 URL에 담는 압축기 / 결과 코드
├─ qr.js         QR 코드 생성기 (직접 구현, 의존성 없음)
├─ config.js     설정 — 공유 모드를 켜는 곳
├─ sample.js     데모 강의 데이터
└─ tools/        검증·빌드 스크립트 (앱 실행에는 불필요)
```

앱을 돌리는 데는 `tools/` 가 필요 없습니다. 정적 서버에 올리면 그걸로 끝입니다.

---

## 쓰는 법

### 강사

1. 앱을 열고 **강사용 화면 열기 → 새 강의 만들기** (또는 **데모 불러오기**)
2. 강의 제목, 요약 섹션, 4지선다 퀴즈를 입력하고 **저장하고 발표 화면 열기**
3. 발표 화면의 **QR을 클릭하면 화면 가득** 커집니다. 프로젝터에 띄우세요.
4. 학생들이 퀴즈를 푸는 대로 **명예의 전당이 실시간으로 갱신**됩니다.

### 학생

1. 휴대폰 기본 카메라로 QR을 찍습니다 (앱 설치 불필요)
2. 이름을 입력하고 입장
3. **강의 요약 / 퀴즈 풀기 / 명예의 전당 / 내 결과** 중 원하는 것을 선택

점수는 `정답 시 배점의 70% + 남은 시간에 비례한 30% 속도 보너스`로 매겨집니다.
그래서 같은 개수를 맞혀도 빨리 푼 사람이 위로 올라갑니다.

## 두 가지 동작 모드

### 로컬 모드 (기본값, 서버 없음)

- 강의 요약과 퀴즈가 **QR 안에 통째로 압축되어** 담깁니다.
  학생 폰은 아무 서버에도 접속하지 않고 강의를 받습니다.
- 점수는 각자의 기기에 저장됩니다. 전체 순위를 모으려면
  학생 결과 화면의 **결과 코드**를 강사 발표 화면에 붙여넣으세요.
- 인터넷이 불안한 강의실에서도 동작합니다.

### 공유 모드 (점수 자동 집계)

`config.js` 에 Firebase Realtime Database 주소를 넣으면 켜집니다.

```js
window.CLASS_CONFIG = {
  databaseURL: 'https://내프로젝트-default-rtdb.firebaseio.com',
  brand: '실시간 강의실'
};
```

- 모든 학생의 점수가 강사 화면에 **자동으로, 실시간으로** 모입니다.
- QR이 짧은 참여 코드 링크가 되어 훨씬 성글고 잘 찍힙니다.
- Firebase SDK를 쓰지 않고 REST + SSE만 사용하므로 추가 스크립트가 없습니다.
  스트리밍이 막히면 4초 간격 폴링으로 알아서 내려갑니다.

데이터베이스 규칙은 강의 시간 동안만 아래처럼 열어두고, 끝나면 닫는 것을 권장합니다.

```json
{
  "rules": {
    "rooms": {
      "$code": { ".read": true, ".write": true, ".validate": "$code.length <= 8" }
    }
  }
}
```

## QR 코드 생성기에 대해

`qr.js` 는 외부 라이브러리 없이 ISO/IEC 18004 규격을 직접 구현한 것입니다.
byte 모드, 버전 1~40, 오류정정 L/M/Q/H를 지원합니다.

검증은 두 단계로 하며, 둘 다 `tools/` 에서 언제든 다시 돌릴 수 있습니다.

1. 널리 쓰이는 `qrcode` 패키지와 약 1,600건의 무작위 입력·경계값을 비교 —
   버전 1~40 전 구간에서 비트 단위로 일치했습니다. (극소수는 마스크 선택만
   달랐고, 그 경우에도 해당 마스크로 생성한 레퍼런스 결과와 정확히 일치합니다.
   마스크 선택은 최적화라 어느 쪽이든 유효한 QR입니다.)
2. 실제로 렌더링한 SVG를 이미지로 굽고 `jsQR` 디코더로 다시 읽어,
   원래 참여 링크가 그대로 나오는지 확인합니다 — 폰 카메라와 같은 경로입니다.

```bash
cd class/tools && npm install && npm test
```

## 배포

리포지토리 루트가 그대로 정적 사이트입니다.

- **GitHub Pages** — `main` 에 푸시하면 `.github/workflows/deploy-pages.yml` 이 배포합니다.
  저장소 Settings → Pages → Source 를 **GitHub Actions** 로 한 번만 지정해 주세요.
  주소: `https://<계정>.github.io/jocodingtest/class/`
- **Firebase Hosting** — 기존 설정 그대로 `firebase deploy` 하면 됩니다.

로컬에서 확인할 때는 정적 서버 하나면 충분합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000/class/
```

`file://` 로 직접 열면 일부 브라우저 보안 정책에 걸리므로 서버로 여는 편이 좋습니다.
